# Changelog

All notable changes to PoultryGuard AI are documented here.

The project follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/). Versions will be assigned when a releasable product milestone is reached.

## [Unreleased] — Product realignment (13 November 2026)

### Added
- Product roadmap aligned to the current PoultryGuard architecture and implementation status.
- Explicit delivery phases for Farm Intelligence UI, operational records, farm-aware decision support, field validation, production engineering and future predictive features.
- Clear separation between working prototype capabilities and planned capabilities.

### Changed
- Repositioned the project description from an ADTC-specific offline assistant to a poultry farm intelligence prototype.
- Rewrote the README to document the current Streamlit, RAG, Groq and SQLite architecture.
- Replaced the stale ADTC sprint plan with a product implementation plan.
- Updated contribution guidance for the current architecture, tests, data safety and attribution.

### Clarified
- Current answer generation uses the Groq API and therefore requires internet connectivity.
- Farm, flock and daily-record services exist, but the Farm Intelligence UI is not yet integrated.
- Farmer and veterinary/extension validation has not yet been completed.
- Historical Copilot co-author trailers are commit metadata; no Copilot collaborator permission was found during this review.
